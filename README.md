# 🧠 AI News Seeker

A real-time AI news aggregator that:
- Fetches latest news on AI, ML, DL, GenAI, Agents, and more
- Summarizes each article using a fine-tuned T5-small model
- Displays content in a clean, interactive Gradio interface

⏳ *Note: Refreshing may take 1–2 minutes as summaries are generated live.*
